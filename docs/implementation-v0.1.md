v0.1.6 检索工程第一阶段：正式扫描与预扫描在同一次目录枚举中识别 Git／清单标记，移除逐目录重复探测；保护路径按进程缓存。SQLite 保存改为记录指纹比较与事务增量 UPSERT／删除，未变化记录不再重写；设置和单项标签通常只写一条记录。仍需序列化、比较全部内存对象，启动仍加载完整索引，尚无 SQL 分页／增量监听／MFT／USN。加入对照 v0.1.5 的隔离基准工具，S0／S1 部分完成；性能结果与限制见 [检索工程基准](performance-v0.1.6.md)。AI 保持冻结。

v0.1.4 当前调整：磁盘下拉框展开时自动刷新磁盘清单；原“刷新磁盘”按钮替换为“预扫描”。预扫描只读遍历同一排除规则下的文件／项目，统计当前可枚举数量，不创建资产、不写库；记录在本次会话内显示，重启不保留。支持暂停、取消、错误／排除计数；全电脑的注册应用／PATH 发现不计入估算。时间暂为枚举耗时 2–6 倍的未校准启发式区间，不保证覆盖 UI／合并／写库开销；取消或错误导致部分范围时不估算总耗时。正式扫描不设固定数量上限，仍受内存、存储、权限和排除规则限制，尚未证明百万资产性能。新扫描策略使旧达限缓存不再匹配，旧记录保留为历史。检索框仅在指定目录模式显示；全电脑／按磁盘模式隐藏并清空筛选。AI 保持冻结。

本阶段界面调整：七项侧栏按总览、AI 分析、扫描与记录、应用清单、文件资产、个人化面板、设置排列。文件资产恢复为独立导航并保留总览快捷入口；个人化面板仍展示项目与环境。AI 页面保留布局和既有记录，预览、分析（含缓存复用）、选择响应及审核暂时冻结，底层 AI／缓存能力保留。记录区使用可选择、可复制的只读 TextBox；正式扫描无固定数量上限，旧达限记录作为历史部分覆盖保留。

日期：2026-10-10；交付基线：v0.1.6。当前为可运行的 Windows 原型，技术栈 C#／WPF／SQLite。

## 本阶段交付

此前实现 AI 建议闭环；当前用户要求冻结 AI 页面，保留扫描、浏览、人工分类与持久化。

核心是 AI 辅助管理，扫描和规则分类为其提供事实输入。首版不接入真实删除、移动或卸载；接受建议只改变索引。没有模型时可人工管理，示例提案保留显示，但当前不能进行 AI 审核。

## 与完整式样书的差距

- 首版不承诺已发现所有软件或有效环境版本；Store 包、便携应用、版本管理器和 WSL 尚未覆盖。
- 项目仅基于标记发现，尚未解析版本约束、识别所有 monorepo／裸仓库或验证分支、脏状态。
- 尚未支持扫描范围检查点与强制中断恢复；正常关闭会等待取消、结束与保存。完成／取消之外的未保存扫描可能丢失。
- 原目录扫描合并新结果并保留旧条目；尚未提供“已消失”核实、文件身份跟踪和增量监听。
- 保护状态采取保守路径和规则，不构成可删除性判断；不做应用与目录的完整归属图谱。
- 没有正文读取、OCR、重复哈希、内容辨别和真实操作计划执行。
- SQLite 当前采用记录级 JSON，尚未有复杂关系表／SQL 分页；搜索以内存列表为主。
- 尚未验证十万／百万文件性能目标、全盘扫描速度或普通用户可用性，不宣称完整通过式样书验收。
- AI 当前是有限批次建议生成，不是自主全盘 Agent，也没有动态工具规划循环。
- 扫描缓存未自动检测文件变化，需强制刷新；AI 是整批匹配缓存，批内一项改变会触发整批重算，尚未按变化项拆分推理。未测大规模缓存性能或真实 API 累计节省。

## 验证

- Release 构建：零错误、零警告。
- 37 项自动检查：新增单次枚举识别全部项目标记、增量写入／删除／顺序／回滚、外部连接变更检测；包含预扫描计数／排除／只读／取消与无默认上限的检查；原有扫描、审核、API 与应用视图检查，加上扫描缓存跳过枚举／刷新／卷和规则隔离，分析跨重启跳过 HTTP／失效／审核保留，过期建议和预览拒绝，失败结果不缓存，v2 索引升级。
- 离屏验证：总览、冻结 AI、可选择记录、设置、应用列表与图标页；断言七项导航、文件入口、AI 预览／调用／审核均被阻止，历史文本可选中。未扫描个人磁盘、未调用真实模型。
- 核心 AI 与缓存能力继续由 HTTP mock 检查；真实 API 权限与响应质量未验证。

接口依据：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[Claude Messages](https://platform.claude.com/docs/en/api/messages/create)。模型默认值可在高级设置调整，不保证任意账号均有权限。

全电脑检索限于本机已挂载固定／可移动磁盘，网络盘、光盘、未挂载卷不在范围；逐范围保存。系统相关依据为注册表 SystemComponent=1、更新 ReleaseType 或 Windows 安装位置，不能据此判断可删除性。旧索引需重新发现应用才能补齐标记／图标元数据。图标布局当前使用 WrapPanel，尚未针对数千应用做虚拟化性能验证。

这些标记是系统相关候选规则，并非 OS 归属证明；SystemComponent 也可用于隐藏普通安装记录。实现依据：[ARPSYSTEMCOMPONENT](https://learn.microsoft.com/en-us/windows/win32/msi/arpsystemcomponent)、[ExtractIconEx](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-extracticonexw)。图标句柄在提取后释放。
