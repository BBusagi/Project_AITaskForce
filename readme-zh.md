# AssetDesk · 个人电脑资产工作台

v0.1.4 当前调整：磁盘下拉框展开时自动刷新磁盘清单；原“刷新磁盘”按钮替换为“预扫描”。预扫描只读遍历同一排除规则下的文件／项目，统计当前可枚举数量，不创建资产、不写库；记录在本次会话内显示，重启不保留。支持暂停、取消、错误／排除计数；全电脑的注册应用／PATH 发现不计入估算。时间暂为枚举耗时 2–6 倍的未校准启发式区间，不保证覆盖 UI／合并／写库开销；取消或错误导致部分范围时不估算总耗时。正式扫描不设固定数量上限，仍受内存、存储、权限和排除规则限制，尚未证明百万资产性能。新扫描策略使旧达限缓存不再匹配，旧记录保留为历史。检索框仅在指定目录模式显示；全电脑／按磁盘模式隐藏并清空筛选。AI 保持冻结。

侧栏依次为：总览、AI 分析、扫描与记录、应用清单、文件资产、个人化面板、设置。文件资产恢复为独立导航，总览保留快捷入口；个人化面板暂沿用开发者视图。AI 分析等待重新设计，暂时保留结构、UI 和已有数据，冻结预览、模型调用、缓存分析、选择响应和接受／拒绝；服务商设置仍可配置。扫描记录改为只读文本框，支持鼠标选择、Ctrl+A、Ctrl+C 与右键复制。原有达限记录为历史部分扫描；新版正式扫描无固定数量上限。

Windows 本地桌面应用，用统一 GUI 理解文件、应用、开发环境与项目，由 AI 辅助粗分类和整理，最终由用户审核。

当前已有可运行的 V0.1 原型。AI 是整理体验的一部分；底层扫描和人工分类可独立工作。

## 启动

需要 Windows 和 .NET SDK 10.0.301 或后续 .NET 10 功能版本，包含桌面组件。本机工具链已满足。

```powershell
.\start.ps1
```

如果 PowerShell 本地策略阻止脚本，可直接执行：

```powershell
dotnet run --project src/AssetDesk.Desktop/AssetDesk.Desktop.csproj
```

已构建的便携版位于 `artifacts/release-v0.1.5/AssetDesk.exe`，需 .NET 10 Desktop Runtime；运行时无需 SDK。整个发布目录需一起保留，不能只复制 exe。

## 使用

1. 在顶部选择“全电脑检索”或“按磁盘检索”（再选磁盘），点击“检索（优先缓存）”。原有指定目录入口保留，也可先体验示例资产。
2. 通过总览内的文件入口、应用清单或个人化面板浏览，按名称、路径、分类或标签搜索。应用清单可切换列表／图标视图，并勾选或取消“显示系统相关应用”；偏好在重启后保留。
3. 在总览点击“查看文件资产”；详情页支持人工分类与标签，重扫保留人工决策。
4. 扫描与记录支持选择文本、Ctrl+A、Ctrl+C 和右键复制。
5. AI 分析暂时冻结，保留结构、界面和历史数据，暂停预览、调用模型与建议审核。

## AI 配置

设置页选择服务商 → 在密码框填写 API Key → 点击“应用设置”。支持 Ollama、OpenAI、DeepSeek、Anthropic / Claude、自定义 OpenAI 兼容服务。官方地址与初始模型自动填入；高级设置可修改模型，自定义服务还需填写 HTTPS Base URL。

密钥使用 Windows 当前用户 DPAPI 加密，各服务商独立保存；输入留空保留旧密钥，填写新值替换，高级设置可移除。密钥不出现在发送预览或服务错误正文中。应用设置不发送资产，分析前仍须确认预览和目标服务商。连接检查只列出模型，不保存草稿设置，也不保证模型生成权限。

本机 [Ollama](https://docs.ollama.com/quickstart) 无需密钥，但需自行启动服务并安装模型；应用不自动安装、启动服务或下载模型。默认地址 `http://127.0.0.1:11434`，初始模型 `qwen3:8b`，可替换为已安装的名称。

采用 Ollama chat、OpenAI 兼容 chat completions 和 Claude Messages 适配器，非流式输出并本地严格校验。未知／重复对象、未授权字段、格式不符或被截断的结果均拒绝。Ollama 限制本机 HTTP，远程 API 要求 HTTPS，禁用代理与重定向。发送范围为预览中的名称、类型、分类、保护状态、大小、版本、标签与用户目标；不发送完整路径和正文。名称、标签和目标也可能含隐私，请检查预览。

## 已实现与限制

检索默认优先复用当前策略下的扫描快照，命中不重新枚举目录；显示快照时间和部分覆盖限制。要发现磁盘上的最新变化，勾选“强制刷新扫描”。缓存匹配范围、挂载卷身份和扫描规则；无法识别卷身份时跳过复用。“刷新应用与环境”始终重新发现软件与工具。取消或失败的扫描不替换原有可复用快照。

AI 缓存匹配整批有序资产、目标、服务商／地址／模型、提示词与契约版本，以及已知元数据（包括修改时间和标签）。命中不调用模型，重启后仍可复用，不重复添加建议、不重置接受／拒绝。采用 AI 建议引起的标签变化会保留该次已审核结果的复用；手动改标签或源元数据改变则失效。勾选“重新分析”会跳过缓存并可能产生 API 费用。设置页可单独清除缓存，保留索引、标签和审核记录。

当前是快照复用，不是自动增量监听：磁盘变化需强制刷新才会发现。分组建议依赖整批上下文，一项改变会令该批分析失效，尚未实现只重算变化项。保留最近 200 批已验证的分析结果；不宣称已测累计节省费用。

- 七项导航：总览、AI 分析（冻结）、扫描与记录、应用清单、文件资产、个人化面板、设置；文件资产独立导航位于应用清单与个人化面板之间。
- 全电脑检索逐盘扫描本机已挂载的固定／可移动磁盘，同时发现应用与 PATH 环境；按磁盘检索只扫描所选盘。网络盘、光盘和未挂载卷不在范围，离线盘、权限错误、取消后未开始的范围均记录。不会自动开始扫描。
- 元数据扫描，默认依赖子树排除、特殊连接／离线占位对象跳过；暂停、取消、局部错误报告；正式扫描无固定数量上限。
- 应用卸载注册信息枚举；PATH 中 Git、Node.js、Python、.NET 候选与文件版本读取，不执行程序。
- 应用图标优先读取本地注册图标资源，不可用时占位。系统相关依据为 SystemComponent、更新 ReleaseType 或 Windows 安装位置；不把所有微软软件或 Program Files 应用当系统组件。隐藏仅影响视图，不删除索引；旧应用记录需点击“刷新应用与环境”刷新这些字段。
- Git 和常见项目清单标记发现；暂不探测分支、解释依赖或运行项目。
- 扫描中显示计数与当前路径；每个范围完成或取消后合并并保存到本地 SQLite。突然断电／强制终止可能丢失当前范围未保存的扫描。
- 重扫保留人工标签；旧记录保留为历史发现，暂不自动核实是否消失。
- SQLite 文件位于 `%LOCALAPPDATA%\AssetDesk\workspace.db`，schema v3 为资产、建议、报告、设置新增扫描／分析缓存表；v1／v2 资产和设置原位保留升级。升级后旧客户端不能打开新版索引。

不执行真实文件整理、不分析正文、不自动提权、不默认发送遥测。清空索引只删除工具自身的数据。

尚未实现：Store／MSIX 包、便携应用全面发现、版本管理器适配、WSL、Git 实时状态、增量监听、崩溃检查点恢复和文件身份跟踪。式样书里的十万／百万文件性能预算尚未验证。
